# RedeemDeck Support / RedeemDeck 技术支持

RedeemDeck is a free, open-source App Store offer-code manager for iPhone and iPad.

RedeemDeck 是一款面向 iPhone 和 iPad 的免费开源 App Store 兑换码管理器。

## Get help / 获取帮助

- Review the [English README](README.md) or [简体中文 README](README.zh-Hans.md).
- Search existing [GitHub Issues](https://github.com/jinwandalaohu66/RedeemDeck/issues).
- Report a reproducible problem with your iOS version, RedeemDeck version, and the steps that led to it. Never include real redemption codes or an unredacted backup.
- Email: [jinwandalaohu940@gmail.com](mailto:jinwandalaohu940@gmail.com)

请先查看 README 和已有 Issue。反馈问题时请附上 iOS 版本、RedeemDeck 版本及复现步骤，但不要上传真实兑换码或未脱敏的备份文件。

## Data recovery / 数据恢复

RedeemDeck stores its library on the device. If you are moving to another device or reinstalling the app, export a `.redeemdeckbackup` file first and store it securely. The developer cannot recover a local library or lost codes.

RedeemDeck 将兑换码库保存在设备本地。更换设备或重新安装前，请先导出 `.redeemdeckbackup` 并妥善保存。开发者无法恢复本地数据库或丢失的兑换码。
